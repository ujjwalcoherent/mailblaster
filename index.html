Section 1 — Gmail App Password

Use a Google App Password (16 characters), not your normal password. Enable 2-Step Verification, then create one at myaccount.google.com → Security → App passwords.

API key not required here

A hosted deployment sets MAILBLASTER_API_KEY so its campaign history cannot be read or deleted by anyone who knows the URL. Paste that value here. It is stored in this browser only, and sent only to this site.

Section 2 — Recipients & Salutations

Paste email IDs in any format — commas, spaces, new lines, or copied from a sheet. Names are parsed from the email ID itself and used as {{name}}.

Resuming after an interrupted campaign? Skip already-sent drops every address that has already been delivered, so nobody gets the same mail twice.
